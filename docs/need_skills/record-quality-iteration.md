## 目标与事先确定的边界

本轮先检验 `record-experiment` 在一次真实、低成本的正式本地基准中是否保留可复核证据。安装范围仍为全部九个技能，不因本轮有限样本改变。

比较 A（不提供目标技能）与 B（冻结的当前技能）。两组使用相同业务事实、持久格式契约、初始项目、工具条件和请求预算；不得删除基线所需的字段定义来人为制造失败。模型请求明确为 `gpt-5.6-sol`，每组两次独立会话，按 A1、B1、A2、B2 分配；允许在独立目录内并行执行。每位执行者请求上限为 20 次工具调用，不启动子 Agent、不联网、不提交或发布。

这是单技能显式提供的开发对照，不是自然触发试验，也不是 GPT-6 或独立保留集验收。当前版本如未出现有依据的问题，不为产生改动而重写；若需修改，保留旧快照和全部旧结果，以同等条件另行复验，并区分静态契约修复和观察到的行为改善。

## 结果标准

本地基准产生一个低于对照的有效指标。执行者应在启动前建立实验记录，一次运行捕获两条原始输出，正确记录终态和不采用的决定，同时保护已有用户文件及归属不明的 Run 目录。

检查器必须先以有意错误的产物验证以下失败能够被发现：重复运行、运行前没有 Record、漏掉 stderr、把有效负结果记成运行失败或采用、改动用户文件。对照不以固定正文标题或模型自评分为依据；正文是否准确解释指标和结论还需协调者读取原始产物核对。

准备阶段冻结初始文件和技能输入。基准启动时保存当时的 Record 与运行计数，用来区分事前留档和事后补录。最终评价不重新运行正式基准来补证据。输入摘要和启动快照依赖受信协调者及未被改动的本地程序，不宣称具有防恶意模型篡改的系统级隔离。

模型正常返回、明确报告阻塞、被协调者暂停分别记录。产物检查通过不能代替自主正常完成；工具预算或协调者介入情况如无法独立核对，就明确标为未计量。失败和中断保留，不用新的成功运行替换。

## 已发现并修订的问题

旧候选一次运行按 Skill 的无条件收尾步骤执行 `docs sync`，生成 `runs/INDEX.md` 后，才发现用户只允许写新 Run 并删除索引。该运行的 Record 正文明确记载了这件事。最终目录干净不抵消执行期间的越界。

中英文 Skill 现已明确：CLI 可用时可做只读 check；只有生成索引的写入属于当前授权范围时才 sync。不为此安装工具或先创建再删除越界文件，跳过索引维护不把有效实验变成失败。

检查器分别输出 `final-tree-writes-only-new-run` 和 `execution-writes-only-new-run`。前者检查最终快照，后者使用绑定文件摘要的协调者审查，允许 true、false、null。已确认越界记严重失败；未知不记通过。`artifact_passed` 只说明实验产物及最终文件检查，不代表整个任务合格。没有完整工具轨迹或文件事件监测时，不用执行者自述无越界来证明全过程无越界。
